KAHVISOTA

A real-time 1v1 arena duel where the outcome is decided by skill alone. No random numbers anywhere in the simulation, a mirrored arena, and every match reproducible from its input log.

Zero RNG Server-authoritative Replay-verifiable HTML5, no COOP/COEP EN / FI Original work, no third-party assets
live build, playable

Practice mode runs against a rule-based bot and needs no server. Stake matches connect to the match server, which runs the only authoritative simulation.

Why an operator would take this

Player versus player with a commission means the house is never a party to the match and carries no game outcome risk. The margin is the commission on settled pots, and a draw refunds both stakes without commission.

Because the simulation contains no random source, the usual RNG certification question changes shape entirely. There is no generator to evaluate statistically. What has to be shown instead is that a recorded match replays to the same result, and that check runs from a command line in seconds against the stored input log.

Every round carries a visible round identifier and a state checksum on screen and in the settlement record, so a player dispute can be answered with the actual match rather than a log line.

Technical facts

Engine and deliveryGodot 4.7, HTML5 build of static files, embedded as an iframe
ThreadsSingle-threaded build, so no COOP or COEP headers are required
Download sizeAbout 40 MB uncompressed, about 10 MB gzipped
OrientationPortrait 9:16, touch and mouse, mobile first
LanguagesEnglish and Finnish, switchable at runtime by the operator
Match length2 min 30 s, plus 90 s overtime on a tie
NetcodeLockstep on a fixed 200 ms input delay, identical for both players
Anti-cheatServer validates every move, clients send state checksums every 2 seconds
Records per roundInput log, final checksum, settlement row with stake, pot and commission
AssetsEvery graphic, sound and music cue is generated by our own code at runtime, so the build contains no third-party art or audio

Honest status

This is a working prototype, not a certified product. Verified by running: the deterministic simulation, replay reproduction, mirror symmetry of the arena, a full networked match between two clients, settlement and the post-match verification tool.

Not done: authentication against an operator session, a real wallet connection, load testing, balance tuning with live players, a security audit and any test-house certification. Balances shown in the build are demo credits and no money moves anywhere.
